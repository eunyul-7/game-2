# 🐥 병아리 슈팅

귀여운 병아리가 내려오는 슬라임을 물리치는 슈팅 게임이에요.

## 👉 [여기를 누르면 게임이 시작돼요!](https://eunyul-7.github.io/game-2/)

게임 주소: <https://eunyul-7.github.io/game-2/>

## 조작법

| | 컴퓨터 | 휴대폰 |
|---|---|---|
| 움직이기 | ← → 또는 A, D | 화면을 손가락으로 좌우로 끌기 |
| 발사 | 스페이스바 (누르고 있으면 연사) | 자동 발사 |
| 일시정지 | P 키 또는 ⏸ 버튼 | ⏸ 버튼 |
| 소리 끄기 | M 키 또는 🔊 버튼 | 🔊 버튼 |

## 규칙

- 목숨은 3개 ❤️❤️❤️ — 슬라임에 부딪히면 하나씩 줄고 적이 더 빨라져요.
- 약 20초마다 레벨이 올라 점점 어려워져요.
- 최고 점수는 브라우저에 저장돼요.
